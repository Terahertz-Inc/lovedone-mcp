# LovedOne Family Inbox for Cursor

Authenticated MCP for one LovedOne family household: loved ones, members, and Family Inbox plaintext.

- Endpoint: `https://api.lovedone.app/mcp/v1`
- Docs: https://docs.lovedone.app/mcp-family · https://inbox.lovedone.app/agents
- Mint a key: https://inbox.lovedone.app/settings/mcp-keys
- Support: support@lovedone.app

## Health information

LovedOne inboxes can hold mail from doctors, pharmacies, and insurers. Responses may include protected health information. Only connect a client you trust with that data, and revoke keys when finished.

Configure `LOVEDONE_API_KEY` under Plugins → Configure after installing.
