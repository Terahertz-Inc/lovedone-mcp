# LovedOne Soft for Cursor

Agency MCP for LovedOne Soft: clients, visits, notes, invoices, and scheduling.

- Endpoint: `https://api.lovedone.app/mcp/vendor/v1`
- Portal: https://soft.lovedone.app
- Agents docs: https://soft.lovedone.app/agents
- Support: support@lovedone.app

Responses can include care data. Configure `LOVEDONE_SOFT_API_KEY` under Plugins → Configure after installing.
